# PC 端温润线性图标与文字对比度设计

## 目标

在不改变现有暖白玻璃布局、数据逻辑和交互流程的前提下，提高次要文字可读性，并用统一的温润线性 SVG 图标替换界面中的功能性 Emoji。视觉方向采用用户确认的 A「温润线性」。

## 平台范围

本轮仅面向 PC 网页端，验收视口为 1440×900 和 1024×768。现有 `@media (max-width: 900px)` 规则保持原样，不为手机端新增适配，也不执行手机端测试。

## 颜色与对比度

- 主文字保持 `#2D2D2D`。
- 次要文字从 `#5A5A5A` 调整为带暖紫倾向的 `#514B57`。
- 弱提示与未选中导航从 `#9A9A9A` 调整为 `#6F6875`。
- 激活状态继续使用现有强调色 `#6C5CE7`。
- 不改变背景、玻璃透明度、阴影、圆角和渐变氛围。

## 图标系统

新增无依赖的 `src/icons.js`，集中维护内联 SVG 字符串。所有图标遵循：

- `viewBox="0 0 24 24"`
- `fill="none"`
- `stroke="currentColor"`
- `stroke-width="1.8"`
- `stroke-linecap="round"`
- `stroke-linejoin="round"`
- 默认 `aria-hidden="true"`，由旁边现有文字承担可访问名称

尺寸分级：导航 20px、普通标题/维度 22px、AI 分析卡片 34px。图标只能通过 `currentColor` 切换默认、悬停和激活颜色，不给不同功能分配不同彩色 Emoji。

## 替换范围

- `index.html`：打卡、亮点改进、日记、日历、AI 分析五个主导航图标。
- `src/checkin.js`：健康运动、学习成长、工作产出、情绪状态四个维度图标。
- `src/highlights.js`：今日亮点、明日改进标题图标。
- `src/analysis.js`：今日分析、本周总结、月度回顾三个卡片图标。
- `src/quote.js`：语录加载和成功状态图标。

星级评分中的 `★`/`☆` 属于评分控件本身，不是功能图标，保持不变。用户输入文本、日记内容和 AI 提示词中的字符不做替换。

## 样式与交互

- 新增 `.ui-icon` 基类以及导航、标题、维度、分析卡片尺寸修饰类。
- 导航默认图标和文字使用 `--text-muted`，悬停提升为 `--text-secondary`，激活状态统一为 `--accent`。
- 为键盘操作增加清晰但克制的 `:focus-visible` 紫色轮廓。
- SVG 设置 `pointer-events: none`，确保点击仍由原按钮处理。
- 不改变导航宽度、标签文字、点击区域或动画时长。

## 代码边界

- `src/icons.js` 只负责图标定义和安全渲染，不处理业务状态。
- `index.html` 不能直接调用 JavaScript 图标函数，因此导航图标由 `src/main.js` 在初始化时按 `data-icon` 注入。
- 其他动态模块直接调用 `icon(name, className)` 生成统一 SVG。
- 图标名称未知时抛出明确错误，避免静默显示空白。

## 验证

- Node 单元测试验证图标输出的统一 viewBox、描边属性、可访问属性和未知名称错误。
- 运行现有全部数据安全测试，确认没有业务回归。
- 运行所有 JavaScript 语法检查和 Vite 生产构建。
- 使用 Playwright 在 1440×900 与 1024×768 验证导航、打卡、亮点、日记、日历、AI 分析和语录区域。
- 检查控制台无新增应用错误，检查键盘焦点在 PC 端清晰可见。

## 非目标

- 不重新设计布局、字体、背景或组件结构。
- 不修改数据存储、认证、同步、导出和保存状态逻辑。
- 不添加 npm 图标依赖。
- 不进行手机端适配或测试。
